Introduction to PRTree

Overview

PRTree implements Probabilistic Regression Trees (PRTrees) in R with a high-performance Fortran backend. Unlike classical regression trees (such as CART), which partition the predictor space using hard binary splits and yield piecewise-constant predictions, PRTrees assign observations to terminal regions smoothly via probability distributions, producing continuous regression surfaces.

A key feature of PRTree is its built-in support for missing predictor values (NA) during both model fitting and prediction, without requiring prior imputation.

For the theoretical foundations of PRTrees with missing data, see Prass, Neimaier, & Pumi (2026), Applied Mathematical Modelling, 117450 (https://doi.org/10.1016/j.apm.2026.117450). For comprehensive implementation details and usage examples, see Prass, Neimaier, & Pumi (2025), arXiv:2510.03634 (https://doi.org/10.48550/arXiv.2510.03634).

library(PRTree)

1. Fitting a Probabilistic Regression Tree

We start with a simple one-dimensional regression problem where the true signal is \(f(x) = \cos(x)\) observed with Gaussian noise.

set.seed(1234)
X <- matrix(runif(200, 0, 10), ncol = 1)
y <- cos(X[, 1]) + rnorm(200, 0, 0.08)

# Fit a PRTree using all observations for training (prop_hold = 0)
fit <- pr_tree(y, X, max_terminal_nodes = 9, prop_hold = 0)
summary(fit)

Tree structure and diagnostic plots

plot_tree() displays the learned split hierarchy along with probability heatmaps at each terminal node (using base R graphics):

plot_tree(fit, max_bins = 10)

When ggplot2 is installed, plot(fit, y) produces model diagnostic panels (Observed vs. Fitted, Residuals, Q-Q plot, and Terminal Node Probabilities):

plot(fit, y, which = c(1, 2, 4, 5), ncol = 2)

Prediction on new data

Use predict() to obtain point predictions (complete = FALSE, the default) or both predictions and the terminal-node membership probability matrix P (complete = TRUE):

X_new <- matrix(c(1.0, 3.14, 6.28, 9.0), ncol = 1)
pred <- predict(fit, newdata = X_new, complete = TRUE)

round(pred$yhat, 4)
#> [1]  0.5717 -0.9948  1.0170 -0.9399
round(rowSums(pred$P), 6)
#> [1] 1 1 1 1

2. Controlling Smoothing Parameters and Distributions

Model parameters can be configured via pr_tree_control() or passed directly through ... in pr_tree().

By default, pr_tree() automatically constructs a grid of candidate smoothing parameters (sigma) scaled to the standard deviation of each predictor and selects the best vector on a holdout validation split (prop_hold = 0.2). You can also inspect or customize this grid using expand_sigma_grid(), or fix sigma_grid to a scalar, vector, or custom matrix:

set.seed(42)
X2 <- matrix(runif(200 * 2, 0, 10), ncol = 2)
colnames(X2) <- c("x1", "x2")
y2 <- sin(X2[, 1]) + 0.4 * X2[, 2] + rnorm(200, 0, 0.15)

# Inspect an automatically scaled sigma grid
grid <- expand_sigma_grid(X2, grid_size = 5, tiny_sigma = 1e-20, verbose = FALSE)
grid
#>

#> ========================================================

#> Features: 2

#> 5            4.6724     4.6821
#> ... (1 more rows)

# Fit using Student's t distribution (df = 4) and the custom grid
ctrl <- pr_tree_control(
  dist = "t",
  df = 4,

)
fit_t <- pr_tree(y2, X2, control = ctrl)

Setting sigma_grid = 0 recovers crisp (hard-split) behavior while expanding automatically to match the number of predictors in X:

ctrl_crisp <- pr_tree_control(sigma_grid = 0, prop_hold = 0, max_terminal_nodes = 6)
fit_crisp <- pr_tree(y2, X2, control = ctrl_crisp)
fit_crisp$sigma
#> [1] 0 0

3. Native Handling of Missing Data (NA)

PRTree handles missing predictor values directly during tree construction and prediction without prior imputation. Two parameters control this behavior:

  • proxy_crit ("mean", "var", or "both"): criterion used to assign incomplete observations during node splits.
  • fill_type (0, 1, or 2): strategy used to compute terminal-node membership probabilities P for observations with NA entries:
    • 0: uniform probability across terminal regions;
    • 1: probability 1 if all observed predictors fall within the region;
    • 2 (default): probability computed using only the observed predictors.
set.seed(2026)
X_miss <- X2
X_miss[sample(nrow(X_miss), 25), 1] <- NA
X_miss[sample(nrow(X_miss), 20), 2] <- NA

# Compare the three missing-data probability strategies
mse_by_fill <- sapply(0:2, function(ft) {
  m <- pr_tree(
    y2, X_miss,
    fill_type = ft,
    proxy_crit = "both",
    max_terminal_nodes = 8,
    prop_hold = 0.2,
    grid_size = 4
  )
  m$mse["validation"]
})
names(mse_by_fill) <- paste0("fill_type=", 0:2)
round(mse_by_fill, 4)
#> fill_type=0 fill_type=1 fill_type=2 
#>      0.4002      0.6990      0.5155

Predictions also work seamlessly when newdata contains partial or complete rows of NA:

fit_na <- pr_tree(
  y2, X_miss,
  fill_type = 2,
  max_terminal_nodes = 8,
  prop_hold = 0,
  grid_size = 4
)

X_new_na <- rbind(
  c(2.0, 5.0),
  c(NA, 5.0),
  c(2.0, NA),
  c(NA, NA)
)
colnames(X_new_na) <- colnames(X2)

predict(fit_na, newdata = X_new_na)
#> [1] 2.134978 2.134978 2.386236 2.386236

4. Cross-Validation and Data Splitting

train_test_split() creates simple random splits, missing-value stratified splits, or k-fold partitions:

set.seed(123)
is_na_row <- apply(is.na(X_miss), 1, any)
folds <- train_test_split(stratify = TRUE, is_NA = is_na_row, n_rep = 5)
summary(folds)

pr_tree_cv() automates both Monte Carlo (method = "montecarlo") and k-fold (method = "kfold") cross-validation, including internal validation for selecting sigma and refitting on the full training folds (update_final = TRUE):

set.seed(123)
ctrl_cv <- pr_tree_control_cv(
  method = "kfold",
  n_rep = 5,
  prop_valid = 0.2,
  stratify = TRUE,
  max_terminal_nodes = 6,
  grid_size = 3
)

cv_res <- pr_tree_cv(y2, X_miss, control_cv = ctrl_cv, verbose = FALSE)
summary(cv_res)
